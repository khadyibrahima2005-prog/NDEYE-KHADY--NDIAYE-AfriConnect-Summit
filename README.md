# AfriConnect Summit
Site vitrine d une conference tech panafricaine fictive,realise dans le cadre de l examen Web

12-14novembre 20260.kigali convention centre.Rwanda

AfriConnect Summit est un evenement fictif qui reunit developpeurs.entrepreneurs et in vestisseur venus de tout le continent africain.
Ce depot contient le site vitrine complet de la conference:presentation,programme,intervenantset inscription.

Fonctionnalites
.Darkmode/Light mode avec sauvegarde du choix(localStorage)
.Navbar dynamique qui change de fond apres 80px de defilement
.Menu Humburger pour la navigation mobile
.compte a rebours en temps reel avant la conference
.compteur animes au scroll
.Onglets pour afficher le programme jour par jour
.Filtrage dynamique des intervenants par thematique
.Validation de formulaire en JavaScript
.FAQ en accordeon realise en css
.Bouton retour en haut de page

Technologie utilisees

.HTML5 semamtique(header,nav,main,section,article,footer)
.CSS3 variable CSS Flexbox,Grid,animations,transitions,selecteurs avances
.Git/Github pour le visionnage
.Boostrap icons pour les icones
.Google fonts
